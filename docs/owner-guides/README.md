# Owner guides

Plain-language, task-focused guides for the business owner / office staff — how
to run the platform day to day, written as onboarding (do this → here's where it
shows for the customer).

Distinct from `docs/app-architecture.html` (for developers) and
`docs/user-guide.html` (general operator manual).

## Guides

- _Pricing guide_ — how to set prices for the three ways a trip is sold
  (per-mile transfer, hourly hire, city-to-city fixed route), and how each
  setting reflects on the storefront. _(in progress)_
