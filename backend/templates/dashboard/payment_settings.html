How these are stored

The secret key and webhook secret are encrypted before they are written to the database, using a key derived from the server's DJANGO_SECRET_KEY. They are never displayed again after saving — only the last four characters. If DJANGO_SECRET_KEY is ever changed, both must be re-entered.
